FileMill Email Pipeline

How Cloudflare, Mailgun, the Tunnel, mill.keywind.cc, and FileMill fit together

Outbound leg (sending the file)

  1. Sender emails an attachment to an address at mill.keywind.cc.
  2. Cloudflare DNS resolves that domain's MX records to Mailgun, which receives the mail via SMTP.
  3. Mailgun's Route matches the recipient and fires store() + notify(), POSTing the fully parsed message (multipart/form-data, HMAC-signed) to https://notify.keywind.cc/mailgun-webhook.

Delivery to the laptop

  1. Cloudflare's edge resolves notify.keywind.cc and routes the request through the Cloudflare Tunnel — a persistent outbound connection cloudflared maintains from the laptop, so no inbound ports are ever opened.
  2. The tunnel forwards the request to FileMill's local HTTP server on localhost:8080, which verifies the signature, parses the payload, and submits a job into FileMill's existing pipeline.

Return leg (sending the result back)

  1. Once the job completes, FileMill calls Mailgun's Send API directly over HTTPS (no tunnel needed for outbound — this leg starts from the laptop itself) with the transformed file attached.
  2. Mailgun relays the reply over SMTP back to the original sender, threaded via In-Reply-To/References so it appears as a reply, not a new message.

Why the tunnel exists at all

  1. FileMill runs on a personal laptop — no static IP, no always-on hosting, often behind NAT.
  2. Mailgun's notify() needs a real public HTTPS URL to POST to.
  3. Cloudflare Tunnel bridges that gap without port-forwarding, and runs as a Windows service so it survives reboots independently of FileMill's own persistence.

Cloudflare's two roles here

DNS host for the keywind.cc zone (holds Mailgun's MX/SPF/DKIM/DMARC records for mill.keywind.cc, and the CNAME for notify.keywind.cc) — and separately, the Tunnel relay that exposes the laptop's local port publicly.

Mailgun's two roles here

Inbound: receives mail via MX, matches the Route, parses and pushes it via notify(). Outbound: a completely separate API call (Send API) FileMill uses to deliver the reply — same account, unrelated code path.
